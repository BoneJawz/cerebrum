## Not filler

The no-learning, mismatched-teacher, identity/remapped, unpaired, and prospective-seed controls are scientifically important. Likewise keep seed derivation/config JSON, event logs, voltage/spike monitors, weight snapshots, checkpoint tests, tie/silence fields, and held-out stimulus artifacts. Their code may be verbose, but they support reproducibility or falsification and should not be removed for visual simplicity.

## Duplication versus independent models

`STDPAssociator` and `DistributedVisualAssociator` repeat a LIF definition and STDP rule, but they are intentionally different configurations today: one has 3 outputs/teacher path, the other has 18 shared units/no output head and a 25-channel sparse visual projection. They are not safe to merge into a configurable class without first formalizing interfaces and checkpoint schemas. Similar-looking argmax/voltage evaluation code across experiments also uses different tie and scoring semantics; consolidate only after defining shared metric contracts.

## Computational overhead visible statically

- State monitors record every output/associative neuron at Brian2’s configured time step. Headless runners often retain full monitor arrays for a network lifetime and slice by index; live controller clears captured monitor arrays. Large sweeps or longer duration would increase memory use.
- Distributed dashboard retains spike monitor buffers for the whole session even though its plotted `ActivityBuffer` is bounded. Its topology is built once and updated in place, which avoids full graph reconstruction each frame.
- Both dashboards refresh Matplotlib figures at roughly 25 ms; the first clears/replots raster data, while the distributed dashboard updates multiple artists and graph highlights. This is a GUI workload, not neural simulation work.
- Many headless conditions reconstruct Brian2 networks to enforce independent initial states. That is scientifically defensible but increases Python/object setup. No performance measurement is asserted here.
- `STDPAssociator` always constructs the teacher group/path, including sensory-only runs. This adds a small fixed population/path for compatibility with legacy teaching controls; it is not currently the main cost.
- Experiment CSV/NPZ serialization, full weight histories, and PNG generation are outside simulated neural compute. The distributed experiment’s `.npz` responses and topology are useful audit data, not model state.
